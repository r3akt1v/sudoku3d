# Sudoku3D — 3D-судоку

Судоку в 3D на Unity: классическая логика 4×4 / 6×6 / 9×9, но клетки и фишки — физические 3D-объекты на игровом столе. Фишки перетаскиваются мышью, есть проверка корректности, подсказки и уровни сложности.

## Особенности

- **Три размера поля** — 4×4, 6×6, 9×9 (3D-доски разной геометрии)
- **Drag & Drop фишек** — физическое перетаскивание 3D-тайлов по столу
- **Проверка ходов** — подсветка корректных/ошибочных размещений, запрет дубликатов
- **Генератор судоку** — алгоритмическая генерация головоломок с решением
- **Подсказки и подсчёт ходов**, экран победы
- **Процедурные 3D-модели и звук** — модели фишек/досок и аудио генерируются Python-скриптами (`generate_models*.py`, `generate_audio.py`)

## Стек

- **Unity 6000.6 (Unity 6)**, C#
- Процедурная генерация мешей/префабов
- Python — генерация 3D-моделей и звуковых файлов для проекта

## Запуск

1. Открыть проект в Unity Hub (версия **6000.6.7f1**)
2. Открыть сцену и нажать Play

Готовая сборка: `Builds/Sudoku3D.app` (не коммитится)

## Структура

```
Assets/Scripts/
  GameManager.cs   — состояние игры, уровни, победа
  SudokuPuzzle.cs  — логика судоку (генерация, проверка)
  BoardCell.cs     — клетка поля
  BoardMetrics.cs  — метрики/валидация заполнения
  TileDrag.cs      — перетаскивание фишек
  UIManager.cs     — интерфейс
  AudioManager.cs  — звук
Models/            — данные/сцены
*.py               — генерация ассетов (модели, звук)
```
